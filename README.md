# topix-jk-theme-01
Welcome to the Jekyll theme for [Topix][tool_topix].

## Installation

Add this line to your Jekyll site's `Gemfile`:

```ruby
gem "mxjkth01"
```

And add this line to your Jekyll site's `_config.yml`:

```yaml
theme: mxjkth01
```

And then execute:

    $ bundle

Or install it yourself as:

    $ gem install mxjkth01
